## Validation Rule Types

### 1. NULL CHECK
```json
{
  "rule_type": "null_check",
  "rule_config": {
    "allow_null": boolean,
    "max_null_percentage": number
  }
}
```

### 2. RANGE CHECK
```json
{
  "rule_type": "range_check",
  "rule_config": {
    "min_value": number,
    "max_value": number
  }
}
```

### 3. ALLOWED VALUES
```json
{
  "rule_type": "allowed_values",
  "rule_config": {
    "values": [array of allowed values]
  }
}
```

### 4. PATTERN CHECK
```json
{
  "rule_type": "pattern_check",
  "rule_config": {
    "pattern": "regex pattern"
  }
}
```

### 5. UNIQUENESS CHECK
```json
{
  "rule_type": "uniqueness_check",
  "rule_config": {
    "allow_null_duplicates": boolean
  }
}
```

### 6. DATA TYPE CHECK
```json
{
  "rule_type": "datatype_check",
  "rule_config": {
    "expected_type": "string|integer|float|date"
  }
}
```

## How to Use

### Quick Start (3 steps)
```bash
# 1. Install dependencies
pip install -r requirements.txt

# 2. Run validation
python validate_data.py -c validation_config.json -d test.db

# 3. Check results
cat validation_report.json
```

### With Parallel Processing
```bash
python validate_data.py -c validation_config.json -d test.db --parallel --workers 4
```

### Programmatic Usage
```python
from data_validator import DataValidationManager
import sqlite3

conn = sqlite3.connect('test.db')
validator = DataValidationManager('config.json', conn)
results = validator.validate_all_tables(use_parallel=True)
validator.print_summary()
validator.save_report_to_file('report.json')
conn.close()
```
